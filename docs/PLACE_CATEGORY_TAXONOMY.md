# Place カテゴリ分類基準

## 目的
Plannerの「やりたいこと」から安定して候補を検索できるよう、店舗名の自由記述だけに依存せず、`カテゴリ1`・食事用途・飲食タグを分離して管理する。

## 飲食店 カテゴリ1
カテゴリ1は原則1つ。店の主業態を表す。

| カテゴリ1 | 主な判定例 |
|---|---|
| ラーメン | ラーメン、つけ麺 |
| そば・うどん | そば、蕎麦、うどん |
| うなぎ | うなぎ、鰻 |
| 寿司・海鮮 | 寿司、鮨、海鮮、魚介 |
| とんかつ | とんかつ、豚カツ |
| 肉料理 | 焼肉、ステーキ、焼き鳥、肉料理 |
| 中華 | 中華料理、中国料理、餃子、炒飯など |
| 洋食 | 洋食、ビストロ、フランス料理、イタリア料理、パスタ、ピザ、グラタン等 |
| 和食・定食 | 定食、食堂、和食、天ぷら、天丼等 |
| 居酒屋・バー | 居酒屋、酒場、バーなどアルコール主体の店 |
| カフェ・軽食 | カフェ、喫茶、コーヒー、軽食中心 |
| ベーカリー・菓子 | パン、ベーカリー、菓子、ケーキ、甘味、アイス等 |
| その他飲食 | 上記に明確に分類できない飲食店 |

## 食事用途
複数可。営業時間と実際の提供内容から判定する。

- 朝食
- 昼食
- 夕食
- 軽食
- アルコール

時間だけで機械的に決めず、提供内容も考慮する。例えば早朝営業のコンビニを朝食店として優先しない。

## 情報確認の優先順位
1. 店舗公式Webサイト
2. 施設・運営者公式ページ
3. 下諏訪観光協会・自治体など公的観光情報
4. Google Maps / Google Places
5. 信頼できる地域情報サイト
6. 口コミ・投稿は補助根拠として利用し、単独では確定しない

## 確信度
- 85%以上: 高確信度。カテゴリ一括整備で一括反映可
- 65〜84%: 中。内容を確認してから反映
- 64%以下: 要Web調査・人手確認

## Maintenance運用
1. `カテゴリ一括整備` を開く
2. 現在カテゴリ・推定カテゴリ1・用途・タグ・根拠URLを比較
3. 高確信度は `高確信度を一括反映`
4. 中・低確信度は公式サイト等を確認
5. 必要なら通常のPlace詳細編集で修正
6. `Planner公開反映用CSVを書き出す`
7. GitHubの `data/place_management.csv` に反映

## 原則
- カテゴリ1 = 主業態（1つ）
- 飲食タグ = 食べられるもの・飲めるもの（複数）
- 食事用途 = いつ・何の目的で使えるか（複数）
- 営業時間・営業日は構造化項目を優先
- 不明なものを無理に自動確定しない
